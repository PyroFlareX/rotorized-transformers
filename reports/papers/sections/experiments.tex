\section{Experimental Protocol}
\label{sec:experiments}
Comparisons are made at equal stored-byte budgets; compute is reported separately. Named targets are 75\%, 50\%, 35\%, 25\%, and 15\% of original stored bytes. Actual serialized tensor bytes and checkpoint-level metadata/header overhead are distinguished. Every run records its configuration, environment, metrics, logs, and artifacts in a uniquely named directory under \texttt{reports/experiments/}.

The seven required baselines are: (1) original dense BF16/FP16 reference; (2) truncated SVD / standard low-rank factorization; (3) SVD-to-Givens; (4) magnitude-pruned sparse matrix; (5) butterfly structured factorization; (6) full-rank rotor/scaler cascade; and (7) optional rotor/scaler plus low-rank residual. All compressed methods use matching byte budgets where representable; storage overhead and any skipped budget-infeasible method are stated explicitly. Report weight reconstruction error, layer activation error, language-model validation cross-entropy and perplexity, task quality where applicable, storage details, and execution measurements separately.

Controls include spectrum-matched random singular vectors and Frobenius-norm-matched Gaussian matrices where applicable. All methods must use identical token windows, tokenizer, context lengths, and decoding/evaluation settings. Calibration data, fitting objective, deterministic seeds/topology, dtype, and compute protocol are recorded. Correctness is first checked on short contexts before longer-context evaluation. Estimates (including formula-derived FLOPs or byte plans) are labeled as estimates and never presented as measured quantities.
